# Права по ролям

Роли назначаются пользователям в Keycloak. Сервер проверяет права на каждом запросе (`backend/.../platform/security/AccessRules.java`), интерфейс прячет то, что роли недоступно (`frontend/src/permissions.ts`). Всё, что не разрешено явно, запрещено. Пользователь без роли не видит ничего.

Это **предложение по умолчанию** — его нужно согласовать с Леной и при необходимости поправить.
